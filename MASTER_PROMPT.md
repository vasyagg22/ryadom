# МАСТЕР-ПРОМПТ — «ДВА ИИ», отдельное Android-приложение

## Роль и результат
Ты — ведущий Android/React Native разработчик, дизайнер мобильных интерфейсов, инженер локального ИИ, тестировщик и релиз-инженер. Реализуй **отдельную устанавливаемую APK** с названием «Два ИИ», независимую от приложения «Рядом» и официального PocketPal. Не заменяй PocketPal, не трогай серверы/базы «Рядом». В конце предоставь **реально собранную и проверенную APK**, SHA-256, версию, подпись, список проверок. Если сборка не выполнена — не называй исходники готовым APK. Пользователь самостоятельно испытывает установленную APK и присылает замечания; затем исправления выпускаются с совместимой подписью.

## Входные условия
- Android 16, телефон Infinix NOTE 40 Pro 5G (фактические аппаратные параметры проверять, не угадывать).
- Модели пользователя: **Gemma 4 E2B** и **Bonsai 8B**. Уточни только при объективной необходимости точный путь GGUF/вариант, а не переспрашивай уже известные названия.
- Возможно, модели уже скачаны внутри PocketPal. Android не позволяет другим приложениям читать его приватный каталог: подключай файлы через системный выбор документов (SAF), импорт/копирование в каталог приложения, без root и обходов прав.
- GGUF-файлы **не включать внутрь APK**: они весят гигабайты, импортируются отдельно.
- Для Gemma 4 E2B анализ фотографий предлагать **лишь когда реально работает vision runtime и подключён совместимый `mmproj`/vision-адаптер**. В Bonsai 8B не обещать изображений без фактического multimodal-контента.
- Голосовой ввод должен выполняться локальным Whisper (`whisper.rn` / whisper.cpp) с явно установленной моделью распознавания. Ответ голосом — локальный TTS или заранее установленный системный офлайн-голос Android. Показать пользователю, когда голос ещё не настроен. Запретить скрытый переход в облако.

## Дизайн и UX
Вдохновение PocketPal и современными мессенджерами — аккуратная самостоятельная версия, не чужой логотип. Оригинальная иконка: два связанных кольца/два собеседника, тёмная сливовая основа, лавандовые и белые акценты. Русский основной язык, корректные светлая и тёмная темы. Компактный чат со скруглёнными сообщениями, адекватными полями, красивым пустым состоянием. При открытии чата понятна выбранная модель и доступность зрения. Никаких неработающих декоративных кнопок. Поддержка крупного шрифта, озвучивания, клавиатуры, состояния загрузки модели, отмены генерации.

## Этапы реализации (выполнять по порядку)

### 01. База и лицензии
1. Изучить open-source PocketPal AI v1.24.0, MIT; сохранить LICENSE и исходное авторство. Для максимально быстрой рабочей версии использовать проверенный `llama.rn`, `whisper.rn`, TTS и RN-экран, а не писать inference с нуля.
2. Зафиксировать точный upstream commit/tag. Писать патч как воспроизводимый скрипт. Не подключать сервисные ключи PocketPal, Firebase, пароли или закрытые онлайн-API.
3. Новый Android package `app.duo.offlineai`, deep-link `duoai`, название «Два ИИ», собственная launcher-иконка. Нельзя нарушать работающий PocketPal на телефоне.

### 02. Менеджер моделей
1. Кнопка **Добавить модель**: выбрать локальный `.gguf` через системный файловый диалог. Импортировать модели один раз, проверять размер и доступное место, информировать о копировании.
2. Удобное переключение активной модели в чате. Понятный индикатор загрузки, выгрузки, ошибки и нехватки памяти. Не держать одновременно 2 тяжёлые модели в RAM по умолчанию.
3. Предложить карточки «Gemma 4 E2B» (текст/фото при поддержке) и «Bonsai 8B» (текст), но не подменять произвольные GGUF файлами неизвестного происхождения. Каталог/скачивание — только по явному действию пользователя и при наличии сети.

### 03. Чат
1. Независимая история для моделей, создание/удаление диалогов, копирование/редактирование/повтор ответа, потоковая генерация, остановка.
2. Компактные пузырьки сообщений, различимые свои/чужие, плавный скролл, комфортная клавиатура, безопасное отображение Markdown.
3. В шапке указать текущую модель, есть ли vision, понятный статус. Сохранять переписку только локально, без скрытых синхронизаций.

### 04. Фотографии
1. Импорт снимка с камеры или галереи через разрешения Android; предпросмотр и удаление до отправки.
2. Отключать кнопку прикрепления с пояснением либо выводить ясную подсказку, когда у модели нет активного зрения. Проверять реальную доступность vision runtime.
3. Обрабатывать Exif/orientation, большие изображения, отсутствие памяти, отмену, отсутствие доступа к камере.

### 05. Голос и озвучивание
1. Отдельная кнопка «Говорить»: захват аудио + локальная транскрипция Whisper, возможность отредактировать перед отправкой, согласие на микрофон.
2. Настройка «Озвучивать ответы» с выбором офлайн TTS-голоса и скоростью, кнопки ▶/⏸/■, запрет аудио с облачного TTS без явного согласия.
3. Опциональный режим «Разговор», последовательность запись → транскрипция → ответ → озвучка, с остановкой по кнопке и обработкой прерываний Android.

### 06. Художественное оформление
1. Два режима: тёмный — #121020 + #A78BFA, светлый — #F8F7FF + #6945D8; хорошая контрастность, плавные состояния кнопок.
2. Переработать иконку, отступы, шапку чата и панель ввода; на узких экранах обеспечить минимум видимого чата, не раздувать интерфейс.
3. Сделать стартовые подсказки «Подключите GGUF», «Настройте голос», «Для фото потребуется модель зрения», адаптировать русские тексты.

### 07. Android и приватность
1. Android 16 arm64, `minSdk` из действующего движка. Не перепрашивать доступ к файлам через устаревший `MANAGE_EXTERNAL_STORAGE`; использовать SAF.
2. Запускать LLM локально, минимизировать фоновую активность; опциональную сеть использовать только для явной загрузки. Приложение должно работать после перезапуска в авиарежиме.
3. Предусмотреть будущую постоянную подпись. Никаких приватных ключей в публичном репозитории. Debug-подпись — **только для пробной версии**.

### 08. Тестирование и выпуск
1. Проверить структуру патча/тесты, build Gradle (Release APK), `apksigner verify`, `aapt dump badging`, SHA-256, размер и архитектуру.
2. Проверить ручным сценарием: установка рядом с PocketPal, импорт Gemma/Bonsai, переключение, чат без сети, отправка фото в vision-модели, отказ для текстовой, офлайн диктовка и озвучивание, выход/повторный запуск, восстановление истории.
3. Передать ссылку на **существующий** APK. Если CI заблокирована подтверждением личности или нет Android SDK — не выдумывать публикацию, отдать код/сборочные скрипты и точно сообщить блокер.

## Релиз-критерии
«Готово для телефона» — только при наличии физического APK, подписи, package ID `app.duo.offlineai`, верифицируемого SHA256 и успешной сборки. «Работает на конкретном Infinix» — только после реального теста на устройстве. Тестовые заготовки и исправленный дизайн не приравнивать к готовой APK.
